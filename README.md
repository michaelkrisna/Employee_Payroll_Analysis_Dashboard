# 💰 Employee Payroll Analysis Dashboard

This project demonstrates an end-to-end simulated HR payroll process using Microsoft Excel, including payroll calculation, attendance integration, overtime calculation, BPJS contributions, payroll deductions, and interactive dashboard reporting.

The project uses a fictional (dummy) dataset created for portfolio purposes. No actual company or employee data is included.

---

## ⭐ Key Features

- Simulated an end-to-end employee payroll process
- Calculated monthly employee payroll using defined business rules
- Integrated attendance and overtime data into payroll calculations
- Calculated employee and company BPJS contributions
- Applied simplified income tax calculations
- Analyzed payroll costs by department
- Built an interactive payroll analytics dashboard

---

## 🎯 Project Objective

To simulate a complete HR payroll process by integrating employee master data, attendance, overtime, allowances, deductions, BPJS contributions, and payroll calculations into a structured Excel-based payroll analysis system.

The project also aims to demonstrate how payroll data can be transformed into meaningful HR reports and dashboard insights.

---

## 📌 Project Overview

This project is a simulated HR Payroll Analytics case developed using Microsoft Excel.

The workbook integrates employee master data and attendance information to calculate monthly payroll components, including basic salary, overtime pay, allowances, attendance bonuses, BPJS contributions, and income tax deductions.

The processed payroll data is then analyzed by department and presented through an interactive dashboard for HR reporting and monitoring.

---

## 📁 Workbook Structure

| Sheet | Description |
|---|---|
| `Employee Master` | Employee master information |
| `Attendance Data` | Daily employee attendance records |
| `Payroll Rules` | Payroll calculation rules and assumptions |
| `Payroll Summary` | Payroll calculation for each employee |
| `Payroll Analysis` | Payroll analysis by department |
| `Payroll Dashboard` | Interactive payroll analytics dashboard |

---

## ⚙️ Business Rules

The payroll calculation uses the following simplified business rules:

- Standard working days are Monday–Friday.
- Saturday overtime is paid at **2× the hourly rate**.
- Meal allowance is provided for employees with **Present** or **Late** attendance status.
- Attendance bonus is calculated based on attendance performance.
- Employee and company BPJS contributions are calculated separately.
- Income tax is calculated using a simplified rate for demonstration purposes.

> **Note:** The payroll, BPJS, and income tax rules used in this project are simplified assumptions created for educational and portfolio purposes. They do not represent actual company payroll policies or current Indonesian tax regulations.
